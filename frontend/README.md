# Mini ERP + CRM Frontend

This project provides the frontend interface for a Mini ERP + CRM Operations Portal built for a wholesale/distribution business.

The application provides a clean and responsive interface for managing customers, products, inventory, stock movements, sales challans, and role-based operations.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Axios
- React Hot Toast
- HTML
- CSS

## Features

- JWT-based user authentication
- Role-based access for Admin, Sales, Warehouse, and Accounts
- Dashboard with operational information
- Customer CRM management
- Product management
- Inventory and stock movement tracking
- Sales challan management
- Draft and confirmed challan workflow
- Stock validation and status tracking
- Responsive and light-themed UI
- Protected routes
- Toast notifications and form validation
